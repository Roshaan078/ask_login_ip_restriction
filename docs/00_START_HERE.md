## 🚀 Quick Start Guide

### Step 1: Download & Extract (1 min)
```bash
# You have: ask_login_ip_restriction.zip
unzip ask_login_ip_restriction.zip
```

### Step 2: Install (2 min)
```bash
# Copy to Odoo
cp -r ask_login_ip_restriction /path/to/odoo/addons/

# Restart Odoo
sudo systemctl restart odoo
```

### Step 3: Activate (2 min)
```
1. Apps → Update Apps List
2. Search "Ask Login IP Restriction"
3. Click Install
```

### Step 4: Configure (5 min)
```
1. Settings → Users
2. Select user
3. IP Restriction tab
4. Toggle "Enable IP Restriction"
5. Click "Add Current IP"
6. Save
```

### Step 5: Test (3 min)
```
✅ Login from configured IP    → Success
❌ Login from different IP      → Blocked
✅ Admin controls restrictions  → Works
```

**Total time: ~15 minutes**
